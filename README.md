# FileAdapt

Browser tools for repairing rejected accounting, ecommerce, banking and filing documents.

[FileAdapt at Burrito’s Labs](https://fileadapt.app/)

## Technology

TypeScript, Astro, React and Cloudflare Workers.

## Architecture

Each utility recognizes a particular file workflow, reports specific faults, applies deterministic changes and revalidates the result. Checkout and the credit wallet operate separately from document processing.

## Product behavior

Files are diagnosed and prepared in the browser. Diagnosis is free, and credits pay for validated output.
